# Tbonk Tasks — практикум по эксплуатации приложения

Трекер задач на Flask + PostgreSQL. Браузерный интерфейс и API работают в одном приложении.

```bash
cp .env.example .env
docker compose up --build
```

Открыть http://localhost:8000. Проверка БД: `/health`.

## Домашние задания

| ДЗ | Исходное решение | Исправления | Материалы |
|---|---|---|---|
| 1 | `hw_1/base` | `hw_1/fixes` | [Объяснение](docs/hw1/Объяснение.md), [отчёт](docs/hw1/Отчёт.md) |

Для каждой домашки есть `hw_x/base` (исходное решение) и `hw_x/fixes` (исправления после проверки). У ДЗ‑1 `hw_1/base` указывает на исходный коммит `dddc941`, а `hw_1/fixes` содержит исправления замечаний. У ДЗ‑2–6 `base` и `fixes` пока указывают на один коммит: дополнительных исправлений нет. Следующая домашка основана на текущих исправлениях предыдущей; её реализацию сравнивают с предыдущей `fixes`, а замечания — между `base` и `fixes` одной домашки.

Тесты полного API используют PostgreSQL и очищают тестовую таблицу. Не запускайте их на БД с ценными данными.
